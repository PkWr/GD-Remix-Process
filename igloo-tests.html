Igloo tests — Spot Room

Twelve short tests of Spot, the image-processing web app, on the Igloo walls. Each one opens the app with a different look; please watch it for about two minutes and note how it runs. It takes around 40 minutes in all. Thank you!

Before you start

  1. Open this page in the browser on the Igloo playback machine (the one that will show the walls).
  2. Optional but helpful: first open the Igloo check page, press Run benchmark, then Copy report and paste it into an email to Patrick.
  3. If you hear music, that is part of the app — a low volume is fine.

For each test

  1. Click Open test. The app opens in a new tab.
  2. Press F to go fullscreen across the walls. (If that doesn't work, press F11.)
  3. Watch for about two minutes, using the “Look for” notes.
  4. Close the tab (Ctrl + W) to come back here, then choose a rating and add any notes.

Shortcut: once the app is open, the number keys 1–9 switch straight to tests 1–9 without leaving fullscreen (tests 10–12 open from this page). D shows an info panel (please mention anything odd it says); press D again to hide it.
