Image uploader

Local-only helper for the workshop laptop. Not part of the deployed display page — just a faster way to get Snapdrop-received photos into assets/seeds/ (live) or assets/demo/ (curated demo), depending on the toggle below, without manual renaming. Needs Chrome or Edge, served over http(s) (same local server you already use for the display page — file:// won't work).

This browser doesn't support the File System Access API, so this page can't write directly into your folder. Use Chrome or Edge on desktop instead, or fall back to renaming files manually in Finder/Explorer before dragging them into assets/seeds/ or assets/demo/.
