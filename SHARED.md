# Shared with Spot Type

The 3D Type layer moved to Spot Type (`../spot-type`, type.pkwr.co) in v2.4.1. Shared code: `controls.js`, `controls.html`, `vendor/`, and the engine in `app.js` / `settings.js` / `style.css` / `index.html`. When you change those, Spot Type picks it up by running `tools/sync-from-spot.sh` in that repo. See its `SHARED.md` for the full list.
